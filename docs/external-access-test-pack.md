## 2. 사전 조건

- [ ] URL이 `https://`로 시작한다.
- [ ] 임시 localtunnel 주소가 아니다.
- [ ] 로그인·비밀번호 입력 없이 첫 화면이 열린다.
- [ ] 테스트에 사용할 자료는 샘플 또는 비식별 자료다.
- [ ] 실제 신청서 원문과 개인 식별정보를 공개 URL에 올리지 않았다.

## 4. 전체 업무 흐름 테스트

### 4-1. 실제 검토자료

- [ ] 실제 검토자료 패널이 열린다.
- [ ] RFP 관리번호 `2026-사이버보안-5`가 표시된다.
- [ ] RFP 과제명이 표시된다.
- [ ] 검토자료 파일 목록이 표시된다.
- [ ] `실제 자료 데모 불러오기` 버튼이 작동한다.
- [ ] 신청기관·연구책임자는 확인되지 않은 경우 `확인 필요`로 표시된다.

### 4-2. 지원서류 분석

- [ ] PDF 샘플 업로드
- [ ] DOCX 샘플 업로드
- [ ] XLSX 샘플 업로드
- [ ] HWPX 샘플 업로드
- [ ] 파일명·용량·상태 표시
- [ ] 문서 분석 실행
- [ ] 과제명·기관·책임자·기간·목적·내용·핵심기술·키워드·목표·성과물 표시
- [ ] 누락값이 임의 생성되지 않고 `확인 필요`로 표시
- [ ] 근거 문서명이 표시

### 4-3. 적격성 검토

다음 8개 항목이 표시되는지 확인한다.

- [ ] 공고 내용과의 부합성
- [ ] 기개발
- [ ] 기지원
- [ ] 의무사항 불이행
- [ ] 참여제한
- [ ] 채무불이행 및 부실위험
- [ ] 과제기획위원회 참여
- [ ] 연구책임자 3책 5공

추가 확인:

- [ ] 적합/부적합/확인 필요 변경 가능
- [ ] 담당자 검토의견 입력 가능
- [ ] 우대·감점 증빙 4개 항목 표시
- [ ] 수정 후 새로고침해도 세션 상태 유지

### 4-4. 기존 과제 및 중복성 검토

- [ ] 검색어 자동 생성
- [ ] 검색어 직접 수정
- [ ] 내장 과제 검색
- [ ] 수동 JSON 또는 텍스트 입력
- [ ] 유사도 후보 표시
- [ ] 8개 비교 기준 표시
- [ ] 중복성 판정 변경 가능
- [ ] 검토근거와 종합의견 입력 가능

### 4-5. 보고서 생성

- [ ] 검토자명 입력
- [ ] 소속/부서 입력
- [ ] 종합의견 입력
- [ ] 최종 확인 체크
- [ ] 예비검토 완료
- [ ] DOCX 다운로드

## 5. 보안 확인

- [ ] 비밀번호가 화면·브라우저 주소·콘솔에 노출되지 않음
- [ ] 비밀번호가 서버 로그에 남지 않음
- [ ] 외부 로그인 정보가 저장되지 않음
- [ ] `/api/eval-materials`에 비밀번호·토큰이 포함되지 않음
